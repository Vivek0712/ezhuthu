# Security policy

Please **do not open a public issue** for a security problem.

Report it privately through GitHub: on this repository, open the **Security** tab and choose **Report a
vulnerability**. Include what you found, how to reproduce it, and the impact you expect. We aim to reply within a
week and will credit you in the fix unless you prefer otherwise.

In scope: the code in this repository and the deployed app at https://d3jz2k92ne5puo.cloudfront.net. Please do not
run load tests or automated scanners against the deployed app; it is rate limited and runs on a small budget.
