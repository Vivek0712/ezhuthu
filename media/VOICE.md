# Ezhuthu voice: what we sound like (video, blogs, LinkedIn)

Built 2026-11-03 by the copy + tone testing team, following `media/MESSAGING_BRIEF.md` "Variant testing". Every
number below comes from `media/FACTS.md` (fact IDs in brackets). Raw panel: 60 round-1 variants (6 formats x 5
voices x 1-2) and 18 round-2 iterations (top 3 per format), each scored by 5 reader personas on 5 criteria (section 6).

## 1. The chosen voice: "From the stone to the stack"

**Open in awe, state the stakes as a mission, speak as the builder, close with receipts.**

1. **Awe and place first** (Thanjavur's wall, Tamil, the kings, Madurai in the stones). Highest Heritage score of any voice (mean
   23.7 of 25) and second-best with the Epigraphist (20.2).
2. **Then the mission stakes** (about 23 epigraphists in 2021). Highest-scoring voice overall in round 1 (mean
   99.9 of 125) and the Judge's favourite (22.7 of 25).
3. **Then the builder, in first person** ("So I built Ezhuthu"). The founder voice scores well with developers
   (19.8) but loses the skeptic and the epigraphist when it leads; it works as the *turn*, not the opening.
4. **Then hard numbers with their qualifiers** (held-out, 413 gaps, "match the editors' restoration"). The
   technical voice is the skeptic's favourite (17.8) and ties for second with developers (19.8), but scores 10.3 with heritage readers when it
   leads, so it goes *last*, as proof.

Why: no single voice won every reader. Every round-2 winner is this blend, and the blend beat the best single voice
in every format (A 106 -> 116, B 102 -> 109, C 107 -> 117, D 108 -> 118, E 111 -> 113, F 105 -> 113). Pure punchy and
pure technical are kept for supporting slots (thumbnails, a carousel slide, a dev-community blog title), never the lead.

Round-1 voice averages (all formats, /125): Social-good mission 99.9 · Awe + heritage 99.3 · Bold founder 91.3 ·
Punchy 87.7 · Hard-technical 77.4.

## 2. Tone rules

1. **The place before the product.** The first line names a stone, a temple or Tamil, not "AI" or "agents".
2. **Bold in words, exact in numbers.** "When it commits, 9 in 10 match" (A7 allows it) is bold; "91%" is not allowed
   (0.908 is 90.8%; never round up). The brief's "91% (187/206)" must be written **90.8%**.
3. **Every result carries its qualifier in the same sentence:** "on 413 held-out test gaps", "match the editors'
   restoration", "at list prices", "fine-tuned, tested; the live app ranks with it" (and the 62.7% is "the configuration scored on TEST before the switch").
4. **Humility is the wow.** "It knows when it does not know" and "doubt becomes the lesson" scored as high with
   the skeptic and the epigraphist as any number. Abstention is a feature; say it proudly.
5. **The human stays in the loop and in the frame.** Learners and epigraphists are the heroes; the agents are the
   apprentice. Never "replaces", "deciphers", "clears the backlog".
6. **Pipeline as craft, not contest.** Show the Graph, the Swarm, the ontology, AgentCore and the fine-tuned
   Strands decision model as the build. No model-vs-model headline. Method comparisons (copy-a-parallel 47.2%,
   5-gram 56.7%) only as a supporting line in long copy.
7. **Tamil first, but checked.** Use எழுத்து ("letter") freely (README). New Tamil sentences need a native-speaker
   check; the Tamil tagline is still pending one.
8. **Plain sentences, first person, ASCII punctuation in blogs** (Builder Center format). Short lines on LinkedIn.

## 3. Do and don't words

| Say | Never say |
| --- | --- |
| an apprentice / apprenticeship tool for Tamil epigraphy | deciphers, replaces epigraphists, clears the backlog, validated by scholars |
| matches the editors' restoration (with N) | correct, accurate, right (about restorations) |
| proposes the worn-away letters; fills when sure; abstains; asks an expert | reads any inscription; restores the original text |
| built with Strands Agents; runs on Amazon Bedrock AgentCore | Strands AI, AWS AI, experimental |
| fine-tuned Strands decision model, tested on held-out inscriptions; the live app ranks with it | a new headline TEST number for the live configuration; "the fine-tuned decider scored 62.7%" |
| a custom ontology served to the agents over MCP | COA / FalkorDB runs; "the ontology makes it more accurate" |
| over 1,000 years (Thanjavur); over 1,100 years (only the 410 Pallava restorations) | 1,100 years for anything else; any city-age figure |
| reads Tamil-script photos; teaches Tamil-Brahmi letters | reads Tamil-Brahmi / Grantha / Vatteluttu from photos |
| Tamil Nadu's temples; Madurai named in 25 editions | "Madurai's inscriptions" for the benchmark (L12) |
| about 23 epigraphists **in 2021** | 23 epigraphists (no year); "a backlog of 70,000"; "60% of India's inscriptions" |
| beats classic methods (copying a parallel, a 5-gram model), in long copy | beats humans, state of the art, first, world's first |
| learner pilot with AWS UG Madurai student volunteers: next | any learner-gain or expert-study number |
| (nothing) | the banned company name; "AWS AI Hero" outside the blog byline (see section 7) |

Power words that scored: *stone, wall, carved, worn away, letter, Tamil first, apprentice, read the stone, when it
commits, it knows when it does not know, doubt becomes the lesson, held-out*. Words that cost points: *anyone,
thousands of stones, no tool existed, reads (alone, for stones), AI magic*.
