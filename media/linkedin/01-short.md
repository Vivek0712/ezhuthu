The great temple at Thanjavur has stood for over 1,000 years, its walls written in Tamil. In 2021, India had about 23 epigraphists to read stones like these.

So I built Ezhuthu (எழுத்து, "letter"): an apprentice for Tamil epigraphy, built with Strands Agents and running on Amazon Bedrock AgentCore.

It turns real inscriptions into 1,469 Tamil-first practice drills. Its Restorer agent proposes the worn-away letters, shows how sure it is, and hands the doubtful ones to an expert.

On 413 held-out test gaps, 62.7% match the editors' restoration. When it commits to a fill, 90.8% do.

Next: a learner pilot with AWS UG Madurai student volunteers.

Try it: https://ezhuthu.sparrowdecider.com
Code (public): https://github.com/Vivek0712/ezhuthu
