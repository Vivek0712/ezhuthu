Title (107 chars):
Ezhuthu: An Apprentice for Tamil Temple Inscriptions, Built with Strands Agents on Amazon Bedrock AgentCore

Description (502 chars):
Identify letters, restore worn-away text and learn to read Tamil inscriptions over 1,000 years old. Built with Strands Agents on Amazon Bedrock AgentCore: a Reader names each carved letter, a Restorer fills gaps from parallel inscriptions with calibrated confidence, the agents look up a custom Tamil epigraphy ontology, a fine-tuned Strands decision model is public on Hugging Face, and a Tutor teaches in Tamil. Matches the editors' restoration on 62.7% of 413 held-out gaps; 9 in 10 when it commits.
