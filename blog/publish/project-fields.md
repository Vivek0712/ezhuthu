Title (107 chars):
Ezhuthu: An Apprentice for Tamil Temple Inscriptions, Built with Strands Agents on Amazon Bedrock AgentCore

Description (485 chars):
Identify letters, restore worn-away text and learn to read Tamil inscriptions over 1,000 years old. Built with Strands Agents on Amazon Bedrock AgentCore: a Reader names each carved letter, a Restorer fills gaps using a fine-tuned Strands decision model and a custom Tamil epigraphy ontology, with calibrated confidence, and a Tutor teaches in Tamil. Before the switch to the fine-tuned model, it matched the editors' restoration on 62.7% of 413 held-out gaps; 9 in 10 when it commits.
