Title (115 chars):
In 2021 India Had About 23 Epigraphists. So I Built an Apprentice for Tamil Temple Inscriptions with Strands Agents

Description (448 chars):
Tamil Nadu's temple walls carry over a thousand years of Tamil writing, and time is wearing the letters away. Ezhuthu is an apprentice for Tamil epigraphy built with Strands Agents on Amazon Bedrock AgentCore: Tamil-first practice from real inscriptions, and an assistant that proposes the worn-away letters, shows how sure it is and asks an epigraphist when it is unsure. On 413 held-out gaps it matches the editors' restoration 62.7% of the time.
